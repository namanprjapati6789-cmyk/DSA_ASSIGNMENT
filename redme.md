# Linked List Management System

## Objective

The objective of this project is to implement and practice Linked List
data structures using Java. The project demonstrates the implementation
of both Singly Linked List and Doubly Linked List with different
insertion, deletion, searching, sorting and other operations.

## Language Used

Java

## Data Structures Used

1. Singly Linked List
2. Doubly Linked List

## Features

### Singly Linked List

The following operations are implemented:

- Insert at Beginning
- Insert at End
- Insert at Position
- Insert After a Node
- Insert Before a Node
- Delete from Beginning
- Delete from End
- Delete from Position
- Delete by Value
- Search
- Update
- Display
- Count Nodes
- Find Maximum
- Find Minimum
- Find Middle Element
- Reverse
- Sort
- Remove Duplicates

### Doubly Linked List

The following operations are implemented:

- Insert at Beginning
- Insert at End
- Insert at Position
- Insert After a Node
- Insert Before a Node
- Delete from Beginning
- Delete from End
- Delete from Position
- Delete by Value
- Search
- Update
- Display Forward
- Display Backward
- Count Nodes
- Find Maximum
- Find Minimum
- Find Middle Element
- Reverse
- Sort
- Remove Duplicates
